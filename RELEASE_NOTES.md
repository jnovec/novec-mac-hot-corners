# NOVEC Mac Hot Corners 0.1.0

First public standalone release for macOS.

All four corners: Mission Control (upper-left), Dictation via Fn+D (upper-right), Screenshot (lower-left), Enter (lower-right).

Download the macOS-universal ZIP asset rather than the autogenerated source archive. Includes both Apple Silicon and Intel executables, an installation script and SHA-256 checksum.

Ad-hoc signed, not notarized. Accessibility permission is required. No n8n needed.
