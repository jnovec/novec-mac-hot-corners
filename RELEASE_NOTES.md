# NOVEC Mac Hot Corners 0.3.0 — Čeština, angličtina, němčina

Nová verze přináší nativní lokalizaci podle jazykových preferencí macOS.

## Novinky
- Automatický výběr jazyka: **čeština (cs), angličtina (en), němčina (de)**.
- Angličtina je výchozí náhradní jazyk.
- Přeložené názvy rohů, nabídky akcí, tlačítka, dialogy, stavové a chybové hlášky.
- Podpora individuálního jazyka aplikace v Nastavení systému → Obecné → Jazyk a oblast → Aplikace (po změně je potřeba aplikaci restartovat).
- Překlady jsou přibaleny do .app a fungují offline.
- Český návod k instalaci v ZIP a samostatná česká/anglická dokumentace na GitHubu.
- Zachované původní funkce a nastavení z 0.2.0.

## Instalace
Stáhni **NOVEC-Hot-Corners-v0.3.0-macOS-universal.zip** z tohoto vydání, rozbal celý ZIP a spusť **install.command**. Instalátor uloží zálohu předchozí verze. Aplikace vyžaduje povolení Zpřístupnění v macOS a případně zapnutí systémového diktování.

## Podpis a testy
Aplikace je univerzální pro Apple Silicon a Intel, podepsaná ad-hoc (bez Apple Developer ID a notarizace). macOS může vyžadovat ruční schválení spuštění a po aktualizaci nové udělení oprávnění Zpřístupnění. GitHub Actions kontrolují kompilaci, obě architektury, podpis a soubory překladů. Chování GUI a oprávnění je vhodné prakticky ověřit na cílovém Macu.
