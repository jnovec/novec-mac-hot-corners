NOVEC HOT CORNERS 0.1.0 — macOS

A lightweight background application for macOS 13 or newer.

CORNERS
  Top-left:     Mission Control
  Top-right:    system-wide Dictation (Fn+D)
  Bottom-left:  Screenshot toolbar
  Bottom-right: Return / Enter

INSTALL
1. Unzip this release completely, keeping the application and install.command
   together in the same folder.
2. On your Mac, open install.command. If macOS blocks the downloaded file,
   use the context menu > Open or System Settings > Privacy & Security.
3. The installer will copy the app to ~/Applications, configure hot corners,
   register automatic login startup and open it.
4. Allow "NOVEC Hot Corners" in System Settings > Privacy & Security >
   Accessibility. Enable macOS Dictation in System Settings > Keyboard.

The app has no Dock icon. Hover in a corner for about 0.35 seconds.

NOTE
This first release is ad-hoc signed but NOT Apple Developer ID signed or
notarized. You may need to approve first opening in macOS Security settings.
On updates, macOS may ask you to approve Accessibility again.
No administrator password, n8n server, or other runtime service is required.
