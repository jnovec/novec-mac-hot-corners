NOVEC MAC HOT CORNERS v0.2.0 — ADDED GUI

An interactive macOS menu-bar application with a four-corner settings panel.

INSTALL:
1. Unzip the entire downloaded release archive.
2. Open install.command next to NOVEC Hot Corners.app.
3. macOS may block the ad-hoc-signed app; choose Open Anyway in Privacy & Security if you trust this package.
4. Grant Accessibility to NOVEC Hot Corners and enable macOS Dictation under Keyboard settings.
5. Choose desired actions from the GUI, available anytime in the menu bar.

CONFIGURABLE ACTIONS:
- Mission Control, Show Application Windows, Show Desktop
- Screenshot, Dictation (Fn+D), Enter
- Custom keyboard shortcut (e.g. cmd+shift+5)
- Run a command in Terminal (use only commands you trust)
- Launch any installed application

Default mappings: TL Mission Control; TR Dictation; BL Screenshot; BR Enter.
Settings persist and update immediately. Login startup runs quietly in the menu bar.
No n8n runtime, administrator password or Docker required.

Signed ad hoc, not Apple Developer ID signed / notarized.
Updating the binary may require re-approval of Accessibility.

Official repository: https://github.com/jnovec/novec-mac-hot-corners
